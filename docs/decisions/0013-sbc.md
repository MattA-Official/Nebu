# 0013. SBC

- **Status:** Accepted
- **Date:** 2026-10-19

## Context

A review of NeOS's stage 4 code led to fixes in
[NeOS #13](https://github.com/MattA-Official/NeOS/pull/13). One of them refuses to
split untyped memory into a piece as big as itself. The compiler turns that check
into an `ngc` (SBC with the zero register), and Nebu halts on it: ADR 0012 implemented
SBCS, and left SBC to halt until something ran it.

## Options

- **Change NeOS so the compiler picks another instruction.** Nebu's job is to run
  whatever NeOS compiles to (ADR 0001), not to steer NeOS's code.
- **Implement SBC** _(chosen)_. It is SBCS without setting the flags, so it shares
  the decoding and the arithmetic.

## Decision

1. SBC is implemented in both register widths.
2. ADC and ADCS still halt Nebu.

## Consequences

- Nebu runs every NeOS test scenario after the stage 4 review fixes, with the same
  output as QEMU.
