# 0005. Licence

- **Status:** Accepted
- **Date:** 2026-10-15

## Context

Nebu needs a licence for the same reasons NeOS does
([NeOS ADR 0005](https://github.com/MattA-Official/NeOS/blob/main/docs/decisions/0005-licence.md)).

## Options

### Option A: The same licence as NeOS

Code and ideas can move freely between the two projects.

### Option B: A different licence

Possible, but it would complicate sharing code between the projects.

## Decision

Adopt **Option A**: Nebu uses the **MIT licence**, as NeOS ADR 0005 decided. The
licence text is in [`LICENSE`](../../LICENSE).

## Consequences

- One licensing decision covers both projects.
